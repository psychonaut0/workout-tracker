# Walkthrough Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the inconsistencies and misleading displays the on-device walkthrough found: Progress defaults, rep-aware change labels, the Today tiles and session banner, Plan header and cards, one stepper style, and the Profile and picker details.

**Architecture:** Pure helpers (default exercise, top-set change, change formatter, label strings) carry the logic and get unit tests. Screens call them. The sign-in-again flow is lifted out of `ProfileScreen` into one shared function, so the Today banner and Profile run the same code.

**Tech Stack:** Flutter (fvm 3.44.0, via `make -C app …`), provider, PowerSync SQLite, gen-l10n ARB (en/it/de/es), flutter_test.

**Spec:** `docs/superpowers/specs/2026-09-27-polish-design.md`

## Global Constraints

- **Commands.** Run everything from the repo root with explicit paths; never `cd`, and never run `flutter` directly.
  - Run `timeout 300 make -C app get > /tmp/x.log 2>&1` first, and again after any ARB edit.
  - Single test file: `timeout 400 make -C app test TEST=<file> > /tmp/x.log 2>&1; echo EXIT=$?`. A bare `make -C app test` gets auto-backgrounded and hangs, so ALWAYS use `timeout` and redirect the output.
  - `make -C app analyze` must report "No issues found".
- **Commits.** Conventional Commits, subject line only, no trailer lines. No plan or task numbers in code.
- **ARB.** Edit en/it/de/es as text and keep the JSON valid. Generated l10n is gitignored.
- **Project rules** (app/AGENTS.md):
  - `Expanded` must be a direct child of its Row or Column.
  - Never create a `db.watch` inside `build()`; cache it in a `late final` field.
  - Use `showWConfirm`/`showWDialog` only.
  - Durations go through `Motion.of`.
  - WStepper contracts: caller space, clamping, and `formatForEdit` whenever the format adds a suffix.
- Every new tappable is at least 48dp and has a Semantics label if it is icon-only.
- Change labels use U+2212 "−" for negatives and the word "same" for zero.
- No layout overflow at 320dp width and 1.3× text in any locale.

## Review Focus

- A user whose most recent session contains only warm-ups, or an exercise since deleted, must still open Progress on something sensible. (Task 2 tests: last-trained id not in the catalog, which falls back.)
- A top-set series with equal weights and equal reps shows "same", not "+0 rep". (Task 1 test.)
- Tapping the Today banner and then backing out of the login screen must leave sync exactly as it was (the reviewed `_signInAgain` behaviour). (Task 3 keeps the shared function; covered by keeping its body verbatim.)
- RIR low stepped above RIR high must pull high up, never save low > high. (Task 6 test.)
- In German at 320dp and 1.3×, the Plan day card meta "Grundübungen · 7 Übungen" must ellipsize, not overflow. (Task 5 test.)

```dart

import 'package:workout_tracker/l10n/app_localizations_en.dart';

void main() {
  final l = AppLocalizationsEn();
  String f(double v) => v == v.roundToDouble() ? '${v.toInt()}' : '$v';

  test('weight change wins when the weight moved', () {
    final c = topSetChange(prevWeight: 100, prevReps: 6, curWeight: 102.5, curReps: 4);
    expect(changeLabel(l, c, fmtVal: f), '+2.5');
  });

    final c = topSetChange(prevWeight: 100, prevReps: 6, curWeight: 100, curReps: 7);
    expect(changeLabel(l, c, fmtVal: f), '+1 rep');

    expect(changeLabel(l, d, fmtVal: f), '−2 reps');
  });
  test('nothing moved reads "same"', () {
    final c = topSetChange(prevWeight: 100, prevReps: 6, curWeight: 100, curReps: 6);
    expect(changeLabel(l, c, fmtVal: f), 'same');
    final n = topSetChange(prevWeight: 100, prevReps: null, curWeight: 100, curReps: null);
    expect(changeLabel(l, n, fmtVal: f), 'same');
  });
  test('negatives use the real minus sign', () {
    final c = topSetChange(prevWeight: 100, prevReps: 6, curWeight: 97.5, curReps: 6);
    expect(changeLabel(l, c, fmtVal: f), '−2.5');
  });
}
```
